# 西席配色驗收紀錄

甲隊基準、1600×987、headless Chrome 軟體渲染，同一鏡頭與同一組取樣像素。值為 OKLab 距離；像素位置為人工選定，遮罩取自改前圖。北席與乙隊不變。

「對地面」取道路、核心平台、購買區甲板三處中最近者（購買區只對購買區甲板）。

其他候選（只量一般與綠色弱）：
- 深紫 `#5a2f9c`、`#4a2a8a`：對地面差距最大（購買區 .31～.33），但綠色弱畫面中核心與北席都是藍，目視比數字更難分，未採用。
- 淡紫 `#bfa2fb`：一般視覺紫感較強，綠色弱下與敵方標記色幾乎相同（.018），北西差也較小。
- 更淡 `#cdb8ff`：北西差較大，對地面略小，紫感較弱。

判定依據：隊伍色系以一般視覺色相界定；色弱模擬下以北西差、跨隊差與對地差為準，隊伍與席位另靠席號、識別桿、徽記、敵我形狀。門檻是看過候選後訂定，用途是防止回退。色弱為 Machado 2009 severity 1 模擬，未請色弱者實看。
