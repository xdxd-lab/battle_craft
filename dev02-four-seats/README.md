# BaattleCraft 四席 2v2｜九兵種人機版

**v6-0（模擬 8）**：[線上入口](battle_craft-v6-0.html)。建置時亦會產生不入庫的 `battle_craft-v6-0-offline.html`；已入庫的 `battle_craft-dev02.html` 是不再重建的 v5-9 歷史快照。以下較早的規則記敘留作歷史。[本版改動、範圍與驗證](../research/BC-V6-0-RELEASE.md)。

離線單檔 `battle_craft-dev02.html`，用瀏覽器開啟即可從選席玩到終局（需 WebGL）。單人加三電腦；根目錄首頁提供線上遊玩與下載入口，v5 保留。

- 建置：`python3 dev02-four-seats/build.py`（或 `npm run build`）。
- 測試：`qa-sim.mjs`（版本 1／2 回歸）、`qa-roster.mjs`（版本 3～6）、`qa-audio.mjs`（合成音訊）與 `qa-audio-play.mjs`（暫停與隱藏時的播放），皆含於 `npm test`；`node dev02-four-seats/qa-browser.mjs`（`npm run test:browser`，需本機 Chrome）。
- 操作：點自己購買區地面、按 `1`～`6`（陸戰隊、重騎兵、飛螳、刺蛇、破壞能、死靈戰機）、點信標上的展示模型、或 WASD／方向鍵移動指揮官；站上信標自動購兵。`V` 切換個人／隊伍視角，空白鍵暫停，速度可切 0.5×／1×／2×（預設 1×），也可觀戰。一般模式切換視窗或分頁後對局繼續；工程模式失焦會暫停。
- 顯示設定：「血條」控制戰場部隊／核心血條與核心血量數字、左側核心條（左側數字保留）；「事件紀錄」只控制詳細紀錄的顯示，即時提示、底層事件與輸入紀錄照常，重開可見關閉期間的近期事件（最多 80 列）。預設皆開，存於瀏覽器 localStorage，重開一局與重新載入保留；無法保存時只在本次生效。
- 預設近景以對局中心尺寸接近星點版的 1.2 倍為目標，保留目前方向的隊伍／個人角度。用「切全景」查看四席與全部通道，再按「切近景」返回。
- 「工程模式」獨立設定，預設關閉。離開視窗或分頁會清除方向鍵和尚未生效的移動指令，保留已生效的點擊目的地。開啟工程模式時，離焦另會暫停，回到遊戲後請手動繼續。一般模式的背景分頁改由計時器推進固定步。更新頻率仍受瀏覽器節流，每次最多補跑一秒。
- 畫質：預設「高細節」，設定中的「畫質：高／標準」按鈕可切回「標準」對照（`#quality=std|high` 只在本次生效）。高細節包含：陸戰隊 976、重騎兵 756、飛螳 436、刺蛇 704、破壞能 776、死靈戰機 448、指揮官 372 三角面（標準 192／148／160／216／196／180／92）、輪廓亮邊與反光材質、960×480 圖卡；甲板嵌板／通風蓋／螺栓／線槽；戰場下方桁架與管線、更深層平台與燈點；2K 甲板底色／粗糙度／法線（合成接縫與倒角）、4K 柏油背景與原 420 星點；3D Garden 燈具與管架改造各見 [assets/3dgarden](../assets/3dgarden/README.md)；畫布像素比至少 1.5、上限 2。只換呈現，模擬與重播不變。
- 地表材質：由畫質決定，沒有獨立按鈕。「標準」對應標準地表（地板 512＋背景 1K），「高」對應精緻地表（2K 甲板＋4K 背景）。舊版保存的地表欄位與 `#surface=` 參數會被忽略。任一張圖載入失敗即改用內建程序材質並提示，對局照常。圖檔來自 [Poly Haven](../assets/polyhaven/README.md)（CC0），內嵌於 HTML。
  - 地板 `painted_concrete_02` 依實際尺寸平鋪，整體亮度依原貼圖平均值校正；背景 `aerial_asphalt_01` 依 30 m 平鋪。席位色、HUD、規則不變。
- 側欄按鈕為兩欄，每鈕一格：暫停／速度、切全景／血條、視角／重新選席、畫質／工程模式、音樂／音效。
- 九信標：版本 7 起每席三欄三列共九座信標（信標半徑 1.35），數字鍵 1～9 對應；購兵列橫式兩列、直式三列。版本 6 為兩欄三列共六座信標，信標中央立著對應兵種的縮小模型（緩慢自轉，自己的指揮官站上時隱藏）；點模型等同走向該信標，不會開單位介紹。補給設備讓位給信標。橫式矮螢幕的購兵列改為單列六鈕。
- 新兵種（版本 7，見 [BC-NINE-UNITS](../research/BC-NINE-UNITS.md)）：戰鬥巡洋艦飛行重型，雷射砲台即時、基礎護甲 3；斥候飛行，對地光子砲、對空兩發反物質飛彈；自殺蟲只打空中、接觸自爆。版本 7 起每次收入 3 金、基礎護甲生效；價格與出兵數暫定，每次一隻。
- 版本 6 新兵種（數值與暫定項見 [BC-SIX-UNITS](../research/BC-SIX-UNITS.md)）：刺蛇地面中型，骨刺為指向性爆炸；破壞能地面懸浮，近距普通攻擊另有濺射（不傷己席、可傷隊友，暫定）；死靈戰機飛行，對地即時雷射、對空飛彈，隱形未實作。
- 聲音：九兵種攻擊音效為原創程序合成。背景音樂是內嵌的 CC0／CC BY 4.0 曲目，分開場（Airy、Pulse、Urgent）與激戰（Space Battle、Claimed by the Void、Volatile Reaction；後者 CC BY 4.0，署名見選單）兩組，進入階段時隨機選一首，任一核心首次受損或滿 90 秒時切換到激戰，畫面顯示目前曲名；見 [BC-MUSIC](../research/BC-MUSIC.md)。聲音在互動後才啟動，音樂與音效可分開調整或關閉，並限制同時發聲。合成部分的來源與限制見 [BC-AUDIO-ROSTER](../research/BC-AUDIO-ROSTER.md)。
- 兵種外觀：陸戰隊為太空裝甲人形，飛螳拍翅；右側單位介紹顯示中英文名稱。
- 道路：版本 4 起可通行寬與畫面同步加寬 10%（半寬 3.6 → 3.96，路面 8 → 8.8）；平台、核心、信標與出兵位置不變。
- 兵種高度層：飛螳在空中（畫面離地並有影子），重騎兵與陸戰隊在地面；兩層互不推擠。飛螳仍沿道路、交會區與核心平台範圍移動。
- 核心：血條旁顯示目前本體血量（與血條開關連動）。外觀依血量分完好、輕損（≤75%）、重損（≤50%）、危急（≤25%），門檻暫定、純視覺，見 [依據與限制](../research/BC-SURFACE-HUD.md)。
- `#seed=數字` 固定種子；「下載本局輸入紀錄」可得種子與逐 tick 指令，用 `sim.mjs` 的 `replay()` 重跑。新對局為版本 7（版本 6 加上三兵種、九信標、收入×3 與基礎護甲），版本 1～6 的匯出紀錄沿用原規則、經濟、信標與座標。

## 結構

- `audio-synth.mjs`、`audio.js`：聲音合成與瀏覽器播放。
- `roster.mjs`、`combat.mjs`：版本 3～6 的兵種數值、傷害、投射物、彈跳、依目標層選武器與濺射。
- `sim.mjs`：30 Hz 固定步的純資料模擬，不碰 DOM、Three.js、`Math.random`、`Date`、三角函式。輸入只有移動指揮官的指令；電腦只決定走向哪座信標。玩家與電腦共用購兵、移動、傷害與勝負規則。
- 每步依同一份位置決定目標與移動，版本 1／2 傷害累計後一起套用，版本 3、4 依固定順序逐發結算，核心失守一起生效，再改派、再判終局。
- 事件帶 tick、席位、隊伍；部隊、指揮官、核心都有席位與隊伍歸屬，供後續可見性使用。`digest()` 產生狀態摘要。
- `main.js` 只讀狀態並把輸入換成指令。場景由 `../dev05-layout/world.js` 建立，與 DEV05 預覽共用。

## 規則與數值

兵種、傷害、護盾、投射物、彈跳、價格與核心數值見 [BC01 規格與實作紀錄](../research/BC01-ROSTER-DAMAGE.md)。版本 5 起始 48 金、每秒 2 金、陸戰隊 7.5 金（版本 1～4 為 12／1／5）；兩次購買至少 15 tick、指揮官速度 .22 沿用 v5；信標半徑 1.6、接敵距離 5 為暫定。8 分鐘起核心過載，保證終局。

- 部隊預設沿原軸攻向對側核心，兩軸部隊在中央依平面距離接敵。
- 對側核心失守後，存活部隊與新部隊改攻另一座敵方核心；不在目標軸線上的先走向中央再折向。
- 失守席停止購兵與收入，存活部隊續戰。兩隊最後核心同一步失守為平手。
- 電腦隨機選信標與購買次數，不看敵我狀況。旋轉 180° 的鏡像比對只驗版本 2；版本 3、4 依編號結算，未宣稱鏡像。
