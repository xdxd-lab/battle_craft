# BaattleCraft DEV02｜四席人機原型

離線單檔 `battle_craft-dev02.html`，用瀏覽器開啟即可從選席玩到終局（需 WebGL）。v5 單機入口保留不變；本原型沒有加到根目錄的 `index.html`。

- 建置：`python3 dev02-four-seats/build.py`（或 `npm run build`）。
- 測試：`node dev02-four-seats/qa-sim.mjs`（`npm test`）；`node dev02-four-seats/qa-browser.mjs`（`npm run test:browser`，需本機 Chrome）。
- 操作：點自己購買區地面、按 `1`／`2`、或 WASD／方向鍵移動指揮官；站上信標自動購兵。`V` 切換個人／隊伍視角，空白鍵暫停，可切 1／2／4 倍速，也可觀戰。視窗失焦會暫停。
- `#seed=數字` 固定種子；「下載本局輸入紀錄」可得種子與逐 tick 指令，用 `sim.mjs` 的 `replay()` 重跑。

## 結構

- `sim.mjs`：30 Hz 固定步的純資料模擬，不碰 DOM、Three.js、`Math.random`、`Date`、三角函式。輸入只有移動指揮官的指令；電腦只決定走向哪座信標。玩家與電腦共用購兵、移動、傷害與勝負規則。
- 每步依同一份位置決定目標與移動，傷害累計後一起套用，核心失守一起生效，再改派、再判終局。
- 事件帶 tick、席位、隊伍；部隊、指揮官、核心都有席位與隊伍歸屬，供後續可見性使用。`digest()` 產生狀態摘要。
- `main.js` 只讀狀態並把輸入換成指令。場景由 `../dev05-layout/world.js` 建立，與 DEV05 預覽共用。

## 暫定規則與數值

| 項目 | 數值 | 來源 |
| --- | --- | --- |
| 起始金幣、收入、購買間隔 | 12、每秒 1、15 tick | v5 |
| 信標 | 5 金 1 台、12 金 3 台；另兩座未開放 | v5 價格 |
| 突擊機 | 3 血、射程 1.62、每 24 tick 傷害 1、速度 .078 | v5 |
| 指揮官速度 | .22／tick，限在自己的購買區 | v5 速度 |
| 信標半徑 | 1.6 | 暫定（v5 為 2.25） |
| 核心血量 | 120 | 暫定（v5 為 60） |
| 主動接敵 | 平面距離 5，同距取編號小者 | 暫定 |
| 過載 | 8 分鐘起所有核心每 2 秒扣 1 | 暫定，保證終局 |

- 部隊預設沿原軸攻向對側核心，兩軸部隊在中央依平面距離接敵。
- 對側核心失守後，存活部隊與新部隊改攻另一座敵方核心；不在目標軸線上的先走向中央再折向。
- 失守席停止購兵與收入，存活部隊續戰。兩隊最後核心同一步失守為平手。
- 電腦隨機選信標與購買次數，不看敵我狀況。四席條件旋轉對稱：換席後的對局逐 tick 鏡像（測試 60 個種子）。
