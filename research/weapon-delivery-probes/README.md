# BaattleCraft 九兵種攻擊：OpenBW 模擬時間測量

2026-11-28（台灣時間）。這是**用官方 StarEdit 資料執行 OpenBW 重實作**的對照，不是 Blizzard 原版客戶端／Remastered 實機紀錄。未改動 BaattleCraft 程式；不分發原始遊戲資產。本報不覆寫 [SPEED 地圖的攻擊／購買考證](../BC-V6-ATTACK-EVIDENCE.md)，以下只測未升級的普通兵種，不使用 SPEED 的英雄或地圖攻擊加成。

## 範圍、坐標及時序

Warmup 12 幀後建立射手 (600,704) 與測靶 (600+距離,704)，射手朝右並下單一攻擊指令。靶大多用無普通攻擊的地面醫護兵（ID34）／空中運輸機（ID11）；兩者均有基礎護甲 1，不能用欄內實際 HP 損失當面板原始傷害。採樣自指令 frame 0 起：首個可見 bullet 快照為「顯示發射」，HP/盾下降為「傷害」。發射快照能已經包含**第一個飛行積分步**，與創建瞬間或 muzzle sprite 起點不必同位置。表中距離是中心距離（原版範圍另用盒對盒計距，故可比 DAT 射程大；過近也可推擠）。只有獨立近例累計，不把固定 frame 估成所有實戰牆鐘毫秒。

### 對 Web 實作有用的邊界

- **射出和傷害目標是兩個欄位。** 死靈式戰機／BC 固定飛行座標，仍保有原傷害目標 ID；普攻命中並非到固定位置做 AOE。死靈式戰機 空對 170px 運輸機：彈 f1 顯示、aim (770,704)，靶移動至 (770,706)，彈 f11 仍在 aim 結束並扣原靶 19 HP。人工把靶橫移 300px 的因果探針也證明四種 死靈式戰機／BC 地空射擊仍抵達原坐標、傷害原 ID，非位置碰撞測試；打掉目標後，彈仍走到原目標點但傷害引用已清空。打掉射手則不取消已射出的彈，獨立四地空實測均仍扣武器傷害。
- **刺蛇的飛出去感覺不等於傷害物體飛行。** StarEdit 動畫 ID18 在攻擊時另建立 muzzle 側 sprite 332（image35/iscript311），七個畫格各 2 幀、沒有飛行或傷害指令；實際傷害是 target-appear #38，sprite353/iscript256。可一起做出口部針刺圖形及目標命中，避免寫成一顆針從出發點位移，碰到才扣血。
- **破壞能**在 target-appear 的特效用腳本 ID268 等 3 幀才判定；用固定命中點及實際傷害當下的位置可表達走離與新進入範圍。以前 Web 固定主目標全傷、範圍中心跟著主目標，並不等於 OpenBW 的濺射。
- **自殺蟲**在接觸建立 source 側效果，不用做第二顆飛過去的彈。OpenBW type6 初始化會標記射手陣亡；傷害腳本 ID292 等 5 幀才呼叫。同一目標可能由別人先擊落，需交給標準活性判定；無理由使自爆變 AOE。
- **近距雷射可以在第一個飛行步就命中。** 以世界尺規 128px = 1.62 換算 muzzle 與逐引擎幀的速度；沿航向前偏 45／75px，逐幀以 raw 加速（單位可按 1/256 px/frame 解讀）；把到達夾在固定目標點而非跨過它。近距可只有軌跡閃光，不要為了所有射擊必定可見而強迫多一幀論理傷害。若視覺風格刻意拉長拖尾，特效壽命不必等於傷害時鐘。
- **資料來源及可重現性：** OpenBW commit 4b046d5f65302b10cb0a745f0fecd37ec85b20a8；試驗地圖 SHA-256 bee65dab73e545d857ad463cbca4a0f2e6986dc8b1cbcf1141b2be39d6801fbd；官方 StarEdit 解包 weapons.dat 80de165015519f9bed46ea8858195c2d2d0120b65b9e55e1c0a50b19135f4b62，flingy.dat 89013fa6d81edad96b68efcfc0bb5342f1c7fa2ef7a0880a71b0169eab13d1ad，iscript.bin cd35e04eaa8ea95cbbccc980bfaf4cae236f4b18b620dfb4a765822ec32c1cd0（與 [PyMS 內附表](https://github.com/poiuyqwert/PyMS/tree/6e325d2e9474716fa2be3aca6479ff7d29dbaab5/PyMS/MPQ)逐 byte 相符）。探針編譯： `g++ -O2 -std=c++17 -I openbw-src openbw-attack-flight-probe.cpp -o attack-flight-probe`，執行的目錄須有 motion-lab.scx 和 StarEdit 的三個資料檔。


### 飛螳彈跳的隔離對照

- P0 飛螳發射位置 (600,704)，P1 四名醫護兵中心為主靶 (700,704)、距主靶最近 (734,710)、較遠 (670,770)、另一名 (810,742)。一枚 ID0 在 f1 出生，f9 打主靶、f12 打較遠靶、f16 才打較近靶。無升級、護甲 1，三次扣 8／2／0.5。最近靶約 34.5px，先選中的較遠靶約 72.5px。這把暴雪指南的就近概述與 [OpenBW 不按歐幾里得距離的空間掃描](https://github.com/OpenBW/openbw/blob/4b046d5f65302b10cb0a745f0fecd37ec85b20a8/bwgame.h#L15590-L15704)區分開。
- [OpenBW 彈跳](https://github.com/OpenBW/openbw/blob/4b046d5f65302b10cb0a745f0fecd37ec85b20a8/bwgame.h#L14300-L14327)使用以當下彈體為心、半寬 96px 的軸對齊區域；在 X 向碰撞盒邊緣索引中找第一名符合武器與敵方條件且不是目前、前一目標的單位。實作簡化時使用「方形＋依碰撞盒邊緣排序」比改成最近可信；同坐標的穩定順序若自訂請明說。[暴雪的文字](https://classic.battle.net/scc/zerg/units/mutalisk.shtml)仍不能當原版細節已測。
- 顯示發射後立刻殺射手：仍 f9 打主靶，無下一跳。殺主靶：f2 失去傷害目標引用，仍 f9 飛到留存坐標，不傷主靶，再 f12／f16 正常打後兩者。還是同一飛行物件、沿原速度與航向轉彎；f9→f10 先往 (700,730)，f11 才往 (682,752)，沒有重新從另一隻怪身上生一枚彈。
- 探針同樣編譯方式，可傳 static、killshooter 或 killprimary；CSV 有四名醫護兵 HP 與目前彈體目標。醫護兵在受傷後會治療，定位三次傷害請讀當幀的下降，不以上一大段血量直接相減。

### 強制位置改變測例對照

以下用探針的 teleport 模式，在首個可見彈體／效果後把同一名靶強制往 Y +300px 移動，用來分辨「飛行繼續追點」「飛行鎖點但傷害鎖人」「只傷當下範圍」三種。它是**因果實驗**而不是原圖的一種移動能力。

- 死靈式戰機 地／空，BC 地／空的效果都在原 Y=704 收尾，原 ID 靶在 Y=1004 照常受傷；不是重新尋找撞到的單位。
- 重騎兵初距 125px，在 f8 發射；靜靶 f16 到達，強制位移後 f21 彈體飛到新點並打中。斥候空對空同樣追到新點，且一輪兩枚可分時抵達。
- 破壞能初距 65px，f23 已出現效果，靜止時 f26 扣血；強制離開後原靶沒扣血。走 4px 仍在範圍，照常扣血。不要預先給主目標一筆不可逃的全傷。
- 自殺蟲初距 45px，f10 開始自毀；強制位移靶也在 f15 扣 109 HP；若同位置時的靶在 f10–f15 先陣亡，則沒有第二筆傷害。接觸之後保留原傷害目標但不再判距。

重現命令範例（source ID、target ID、初始中心距離、可選介入）：

```sh
./attack-flight-probe 8 11 170 teleport
./attack-flight-probe 66 34 125 teleport
./attack-flight-probe 68 34 65 teleport
./attack-flight-probe 47 11 45 killtarget
./bounce-probe static
```
