# BaattleCraft 現況與後續交接

最近接手核對：2026-11-28。四席 2v2 的玩家可見版本定為 **v5-9**；目前模擬／重播格式仍為 7，後續開發從 **v6-0** 起，不回改歷史版。此頁描述目前的 Web 試作與待決事項。原作研究、歷史交接快照及試作規則分別保留在對應文件中。

## 目標與已確認的操作方向

- 目標玩法是小房間四人 2v2，四個方向的部隊沿十字路線進軍，在交會處作戰，通常繼續前往對側。1v1 只使用其中一條路線，是目前單機原型的簡化情境。
- 購兵信標設在作戰區之外。隊友可看到彼此走向哪個信標並預判購兵意圖；敵方應受戰爭迷霧限制。角色踩上信標且金幣足夠時立即購買，站著等金幣補足會自動購買，持續站著則在下一次金幣足夠時再次購買。v5 用至少 0.5 秒的購買間隔作原型節流。
- 金幣、購兵、出兵、碰撞、傷害與勝負需要一致判定。純裝飾視效可在各裝置本地呈現。同步架構尚未選定。
- 美術方向是原創的半寫實／寫實工業科幻 3D 戰場，清楚呈現敵我、兵種、十字路線與場外信標。現有模型與橫幅是試作與概念資料，不代表正式美術定稿。

## 開放議題與下一步

### DEV01 與 DEV02 本機交付

- 四席原型的程式基準為 `b848743`。支援選任一席，由三席電腦補位，沿兩軸購兵推進、接敵、改派及判定終局。下載 HTML 後可用支援 WebGL 的瀏覽器離線遊玩。[四席離線版](../dev02-four-seats/battle_craft-dev02.html) · [DEV01 與 DEV02](DEV01-DEV02-SLICE.md)
- t2p 回報 v5 瀏覽器 9 案例、四席模擬 12 案例與瀏覽器 5 案例通過，瀏覽器與 Node 結果一致。全電腦 1,000 局各有終局，局長中位數約 6 分 7 秒。
- 後續覆核發現，方向鍵與暫停發生在同一步之前時，恢復後會延續待處理的方向指令。DEV 已修正，並用 Chrome 對四席各測按鈕、空白鍵與失焦暫停，核對恢復後位置、扣款、重播與按鍵再啟動。離線 HTML 的 SHA-256 為 `30ab30b9836df891e0b0c84900726fabb2877437bcf050b7563dfb45b0e7ffc4`。
- 西席採用冷紫作為四席試玩基準，保留席號與徽記輔助辨識。綠色弱模擬主要靠明度辨識，藍色弱模擬下與地面對比較低，留待視覺驗證。核心 120 HP、開局第 8 分鐘開始過載，沿用為本輪測試值，後續可隨兵種、經濟與對局節奏調整。
- QA1 每席以相同的 30 個種子各跑一次零輸入對局，共 120 局，其他三席由電腦控制。玩家核心失守的各席中位數為 47～48 秒；整隊敗北的各席中位數為 72～73 秒，全批範圍約 50～92 秒。時間為模擬時間，結果適用於現行電腦策略。零電腦、零輸入的另一次測試確認 8:00 觸發過載、8:02 首次扣血、12:00 平手。首次遊玩的準備時間偏短，列入 DEV07 新手試玩。
- 觸控、失焦、其他瀏覽器及實機效能待驗。四席目前以固定步模擬與逐席事件記錄支援重播，連線、正式迷霧及 WebGL 備援仍待開發。
- 可從這個可玩基準接續兵種外觀、背景和原創命名。原作兵種資料見 [SC1 兵種與介面字詞](BATTLECRAFT-UNIT-REFERENCE.md)。

目前的實作與研究工作已建立 [GitHub Issues](https://github.com/xdxd-lab/battle_craft/issues)，供接手者追蹤。以下條目仍包含需要使用者確認的設計決策。

- **DEV02｜四席驗收。** 離線原型已交付。實際四人同房玩法、操作節奏與隊內合作仍待驗證。[GitHub #1](https://github.com/xdxd-lab/battle_craft/issues/1)
- **DEV03｜一致判定與連線。** 已有本機固定步模擬與重播基準。房間、判定端、四人同步、延遲、斷線與公平性待驗證。[GitHub #2](https://github.com/xdxd-lab/battle_craft/issues/2)
- **DEV04｜戰爭迷霧。** 驗證隊友能觀察購兵意圖，並界定敵方可見的角色、信標、購買結果與部隊資訊。[GitHub #3](https://github.com/xdxd-lab/battle_craft/issues/3)
- **DEV05｜3D 美術與實機。** 原創兵種外觀、背景與命名待設計，目標桌面與手機的場景表現及操作待驗證。[GitHub #4](https://github.com/xdxd-lab/battle_craft/issues/4)
- **DEV06｜原作檔案。** 已整理鏡像地圖與版本證據，原論壇附件身分待核實。[GitHub #5](https://github.com/xdxd-lab/battle_craft/issues/5)
- **DEV07｜對局節奏與規則。** 新手試玩先量測從開局到首次移動、理解站樁自動購兵、首次成交的時間，再評估是否加入引導或練習模式。一般對局沿用本輪數值。經濟、核心、過載、飛行兵、魔法與全地圖控制仍可按後續試玩調整。
- **DEV08｜顯示設定。** 血條與工程師事件紀錄的切換待實作，目前維持可見。

## 研究證據及本機封存

2026-11-26 的 DEV05 四席版面預覽已在本機 `dev05-layout` 分支交付（`8d95663`）。以 16:9 橫式為主，北／西／南／東的場外購買區各在西北／西南／東南／東北。甲隊使用冷色，乙隊使用暖色，每席各有主輔色及席號。全景可切成固定隊伍基準或自己在下方中央的個人基準。獨立 `npm test` 和三張桌面畫面目視通過；鏡頭實際轉場、手機實機及更完整的效能量測待驗。購買區在隊內的相鄰關係不同，規劃迷霧時要用兩席各自的畫面驗收。

GitHub 目前保留研究結論、樣本雜湊、購買表、公開來源連結、交接快照和遊戲建置來源。`research/local-source/` 的 SCX 地圖、CHK 與完整 Trigger 匯出仍在本機；[研究報告](battle_craft-research.md)說明如何按鏡像、雜湊與工具版本重新取得和分析。原論壇 RAR 尚未取得，鏡像版本與該附件的逐位元組關係未能確認。

DEV06 新增 [15 組地空兵種與用詞比對](BATTLECRAFT-UNIT-REFERENCE.md)，並在[研究報告的歷史畫面段落](battle_craft-research.md#歷史畫面與介面)記錄 SC1 鏡像資料與 SC2 作者實機畫面的來源界線。

本機 `.original-html/` 和 Downloads 的歷史 HTML 已比對。只有原始 v3 的購兵邏輯有實質差異，已收錄為[最初交付的 v3 快照](archive/battle_craft-v3-original.html)；其他差異是標題、下載檔名或授權註解的呈現，無需重複入庫。私人對話連結收於本機 `research/local-source/CONTEXT-LINKS.md`，GitHub 交接以此頁及[開發指南](DEVELOPMENT.md)為準。
