## 碰撞矩形不是裝甲分類

[BWAPI 固定提交 d727fed 的 unitDimensions 陣列](https://github.com/bwapi/bwapi/blob/d727fed68558c506163048ea889131d8cbb33915/bwapi/BWAPILIB/Source/UnitType.cpp#L960) 依單位 ID 提供各方向的邊界像素數。寬 = 左＋右＋1，高 = 上＋下＋1；不讀同一列前兩欄的建置格尺寸來充當碰撞盒。[BWAPI API 定義](https://bwapi.github.io/class_b_w_a_p_i_1_1_unit_type.html) 與 [OpenBW 的地圖座標邊界計算](https://github.com/OpenBW/openbw/blob/4b046d5f65302b10cb0a745f0fecd37ec85b20a8/bwgame.h#L710-L728) 可交叉核對；OpenBW 是獨立實作，不代表 StarCraft 接戰流程已實測。

## 確認／待驗

- 以原作邊界資料做地面佔位。優先保留四邊及寬高比例，用一個全體共用的像素→世界單位比例來校準；不按裝甲分類、3D 模型輪廓或每種兵各自猜半徑。比例尚待實際會車和堵塞測試。既有射程／濺射的換算與佔位比例分開，不在這次順手改傷害公式。
- 空中允許穿行與暫時重疊，保留緩慢軟分散；未交戰時較明顯，攻擊間歇（包括對地）仍可慢慢分開。驗證近距離的破壞能仍可濺到聚集的空軍。
- 使用者確認：**相對現行通道加 20%**，可小幅四捨五入。現行畫面路寬 `8.8`，提案 `10.6`（精確值 `10.56`）；地面單位中心的直線通行寬 `7.92`，提案 `9.5`（精確值 `9.504`，半寬 `4.75`）。兩者目前本就不同；新碰撞盒還要檢驗貼邊時不越過路緣。中央交會區及核心平台不當成直線道路一併乘倍率；另驗接縫、出生點與購買區淨距。
- 不以匹配 v5-9 的同種子勝負作為 v6-0 的驗收門檻。優先看佔位、通行與各兵種的可觀察行為；舊版相容與新模式的正確性分開。購兵金額、收入與每次購兵數留到平衡階段；尚未談定的特殊技能不預設。

## 2026-11-28（台灣）：四個移動欄位與接戰節奏

來源：[scmJS 的 flingy.dat 欄位](https://docs.scmjs.dev/api/data/#flingydat)、[OpenBW 的加減速和轉向](https://github.com/OpenBW/openbw/blob/4b046d5f65302b10cb0a745f0fecd37ec85b20a8/bwgame.h#L8624-L8747)、[煞車距離](https://github.com/OpenBW/openbw/blob/4b046d5f65302b10cb0a745f0fecd37ec85b20a8/bwgame.h#L13416-L13425)、[開火檢查](https://github.com/OpenBW/openbw/blob/4b046d5f65302b10cb0a745f0fecd37ec85b20a8/bwgame.h#L2830-L2881)。OpenBW 是獨立實作；以下為資料與程式靜態查證，未量測 Blizzard 原生引擎。

- **Top speed** 是持續移動的速度上限；BWAPI 已換成 px／引擎 frame，DAT 原值才是 1/256 px／frame。自殺蟲約 6.67 vs 戰巡 2.5，這個大差距是專業剋兵的用途，不能預設把它縮小。
- **Acceleration** 原值除 256 是每個 frame 的速度改變量（px／frame²）。例如自殺蟲 107 → 0.418、戰巡 27 → 0.105。數值型移動路徑以此加減速，未達最高速的起步時間不只取決於加速度，也取決於要加到的速度。
- **Halt distance** 不是減速度、倒數或等待時間，原值除 256 是像素距離。OpenBW 在資料控制（type 0）、原始滿速且加速度未變時使用表值；同一模式下速度或加速度不同則用近似 `v²/(2a)` 估距。戰巡 `7585 → 29.63 px`、自殺蟲 `13616 → 53.19 px`、飛螳 `21745 → 84.94 px`。快的單位即使減速較有力，也可能需要更長的停車距離。其他移動控制模式不能照搬這套公式，動畫控制的步進尤其要先查。
- **Turn radius** 是原始的轉向速率參數，不是圓的幾何半徑。OpenBW 每次只改有限的朝向，部分 movement type 還會折半。攻擊時另外核對面向容許角、武器射程、冷卻及攻擊動畫。不要把一個 turn 值直接填作「等幾秒」；也不要把地面停穩再開火的 Web 設計誤寫為所有原作單位一律如此。

玩法備忘：守方可能在敵軍只剩四分之一進路才出專業剋兵；贏交換、守住核心、能否推回去分開觀察。X D 提到反應慢一拍可能損失約四分之一至三分之一核心血量，是節奏例子，不設成固定扣血。後續量測同一路線分離起步、連續前進、90°／180° 轉向、開始煞車到停下、停下到第一發、飛彈命中；比較自殺蟲攔戰巡早一拍與晚一拍的結果，不以舊版同種子勝負作門檻。
