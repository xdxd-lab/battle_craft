- SPEED 的四筆購兵與四種單位生命、護甲及六組武器的 UNIx 基礎傷害、升級增量，在十份鏡像均對得上。SPEED #54 是觸發器編號，它生成 ID 37，並不是英雄 ID 54。原圖每種各有一個預放單位；購兵是唯一以各 ID 明寫生成的觸發器。在 v2.91f，ID 54 還是踩旗選兵及啟動技能的單位，存在多處預放、站位判定、移動及技能後重生；同一 ID 也在 #96 生成 25 隻。不能替換全圖 ID。
- SPEED 的開局四席已啟用 Charon Boosters、Metabolic Boost、Adrenal Glands。普通巨人對地 6 格、英雄 5 格；對空都是 8 格（普通型靠升級，英雄內建）。巨人對空的兩發是各自的傷害。兩種巨人共享腳本、尺寸與行走表現。普通異形蟲和英雄同為地面小型，基礎冷卻 8 源幀、名義射程 15 px；英雄內建加速攻擊，普通在這張圖也已開快速攻擊升級。移速升級則只作用於 ID 37。[固定 OpenBW 的升級邏輯](https://github.com/OpenBW/openbw/blob/4b046d5f65302b10cb0a745f0fecd37ec85b20a8/bwgame.h#L15370-L15416)。
- 以固定 OpenBW、空地直線、等同地圖移速升級、出發後源幀 30 到 80 的實測：兩種巨人都是 4.52 px／幀；異形蟲 37 升級後 7.92、未升級 5.46，英雄 54 皆為 5.46。數字是該條測試的平均行進速度，不是引擎欄位或所有地形的保證。
- SPEED 的普通型確實更貴、更強，另一版的高價型則使用英雄 ID。這能確認各版本配置不一，不能據此確定作者是否有意、或曾經把槽位放反。忠實重現 SPEED 應保留其資料；如自家遊戲採強力英雄，可用 ID 54 為來源、另訂試作屬性，不要寫回原圖表，也不要只改名字與 ID 卻忽略移速／攻速差異。
