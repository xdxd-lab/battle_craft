# BC01 首批三兵種與傷害規則

整理日期 2026-11-26。首批為 Marine（陸戰隊）、Dragoon（重騎兵）、Mutalisk（飛螳）。四席單機版（模擬版本 3）已依本頁實作，實際採用值見第五節。

內容分三層，請勿混用：

- **使用者定案**：本作要照做的規格。
- **原圖／引擎證據**：舊版地圖與 StarCraft 引擎資料，供參考，不是本作平衡值。
- **暫定建議**：DEV 建議，定案前可改。

## 一、使用者定案

| 兵種 | 裝甲 |
|---|---|
| Marine | 輕 |
| Dragoon | 重 |
| Mutalisk | 輕 |

- 三兵種攻擊類型各異。Dragoon 為 E「指向性爆炸」。另兩者的類型尚未定案。
- E 對本體傷害倍率：輕 **50%**、中 **75%**、重 **100%**。中裝甲較少見，首批三兵種沒有。
- 護盾沒有裝甲類型。先以**原始傷害**扣盾；破盾後**剩餘的原始傷害**才依本體裝甲倍率扣血。
- Dragoon 有血量與緩慢回復的護盾。光球飛行時間肉眼可見，延後抵達與命中。
- Mutalisk 首擊後最多再彈跳兩次，逐跳減傷。

### 追加定案：依原版引擎行為

2026-11-26 使用者決定：傷害取整、回盾參數、不足 1 點護盾的吸收判定以原版引擎行為為準。兩張原圖把 Dragoon 護盾設為 0 屬地圖覆寫，**BC01 保留護盾**。

下表依 OpenBW 原始碼整理，作為目前可查的引擎行為依據；查核限度見表後。

| 項目 | 規格 | 證據（`bwgame.h`／`util.h` 行號） |
|---|---|---|
| 數值精度 | 傷害、血、盾為 1/256 定點；武器傷害起始值為整數 | `util.h` L704；`bwgame.h` L13463 |
| 取整 | 彈跳除數與倍率都捨去 1/256 以下（正值即向下取整） | `util.h` L631–636、L667–673；L13662、L13693–13696 |
| 整發下限 | 除數套用後、扣盾前，不足 0.5 點者提高為 0.5 | L13664 |
| 盾的吸收門檻 | 盾 ≥ 1 點才吸收；不足 1 點時整發照本體倍率打血，剩餘盾量不變 | L13673 |
| 扣盾與破盾 | 盾 ≥ 1 點時先吸原始傷害（不超過盾量），剩餘部分扣本體護甲、再套倍率 | L13674–13701 |
| 本體下限 | 該發完全沒扣到盾時，本體傷害不足 0.5 點者提高為 0.5；有扣到盾則不補 | L13708 |
| 死亡判定 | 傷害 ≥ 剩餘血量即死亡 | L13621–13650 |
| 回盾 | 未滿時每 frame +7/256 點，不超過上限；回盾程式沒有受擊延遲或戰鬥中斷條件，盾歸零後照常回復 | L1214–1220 |
| 畫面數值 | 引擎的可見血量向上取整、盾量向下取整 | L815–819 |

由此推得：盾回到 1 點（256/256）前不擋傷害；從 0 起需 37 frame。

護盾升級會先減免打在盾上的傷害，護甲會在破盾後扣減；首批沒有升級，原圖基礎護甲為 0。

**未驗證處**

- 證據來自社群重製引擎的靜態閱讀，沒有用原版遊戲實機、重播或 Blizzard 原始程式核對。
- 每秒回盾量取決於 frame 時間。以常見的 Fastest 42 ms／frame 換算約 0.65 點／秒，此 frame 時間未在本次查閱的原始碼核對，遊戲速度基準也未定。
- 本作模擬為 30 Hz，與原版 frame 不同。換算方式未定；一個做法是累計經過的原版 frame 數（`floor(tick × 1000 / (30 × 42))`），每 frame 加 7/256，避免每 tick 捨入誤差（建議）。
- 回盾與投射物命中在同一 frame 內的先後順序未核。
- 畫面取整只查了引擎的可見值函式，原版 HUD 顯示未核。

### 例

100 點 E 打「40 盾、輕裝甲」目標：

1. 盾扣 40，剩餘原始傷害 60。
2. 60 × 50% = 30，血扣 30。

同樣條件下，中裝甲扣血 45，重裝甲扣血 60。若盾有 100 以上，100 點全部扣盾，血不受影響。首批帶盾的只有重裝甲 Dragoon，倍率 100%；輕、中裝甲帶盾的情況須用測試用單位驗證。

## 二、原圖與引擎證據

### 來源與限度

- 原圖：本機留存的 FastBlack v2.91f（下稱 FB，SHA-256 `d2373a4c588e3a879fda68dd2e8031a33f3a7c740ed94482d4fd6ec0ff9f1cf1`）與 SPEED 鏡像 [2tzpVkp9](https://scmscx.com/map/2tzpVkp9) 的 CHK `UNIx` 單位欄與武器傷害欄。地圖檔不隨儲存庫分發，雜湊見[樣本表](battle_craft-scx-checksums.csv)。兩者都未認證為原論壇附件。
- 引擎預設：[BWAPI d727fed `WeaponType.cpp`、`UnitType.cpp`](https://github.com/bwapi/bwapi/tree/d727fed68558c506163048ea889131d8cbb33915/bwapi/BWAPILIB/Source)。
- 引擎行為：社群重製引擎 [OpenBW `bwgame.h`](https://github.com/OpenBW/openbw/blob/4b046d5f65302b10cb0a745f0fecd37ec85b20a8/bwgame.h)（查閱版 SHA-256 前碼 `5ee316ca2c008c92`，下列行號指此版）。未以實機或重播核對。
- 兵種購買與尺寸比對見[兵種與用詞比對](BATTLECRAFT-UNIT-REFERENCE.md)。

### 數值

| | Marine | Dragoon | Mutalisk |
|---|---|---|---|
| 引擎體型 | 小 | 大 | 小 |
| 引擎傷害類型 | 普通 | 爆炸 | 普通 |
| 合法目標 | 地、空 | 地、空 | 地、空 |
| 濺射半徑 | 0 | 0 | 0 |
| 射程 px／冷卻 frame | 128／15 | 128／30 | 96／30 |
| 引擎預設 HP／盾 | 40／0 | 100／80 | 120／0 |
| FB 普通型 HP／盾／傷害 | 400／0／65 | 700／0／215 | 800／0／125 |
| SPEED 英雄型 HP／盾／傷害 | Raynor 300／0／50 | Fenix 720／0／180 | Kukulza 750／0／125 |
| FB 礦／數量 | 150／15 | 200／12 | 300／8 |
| SPEED 礦／數量 | 150／12 | 200／12 | 300／12 |

三型在兩圖的基礎護甲皆為 0；升級與觸發交互未驗。原作以小／中／大體型決定倍率，本作的輕／中／重沿用相同的 50／75／100%。

與使用者定案的差異：原作 Marine、Mutalisk 同為普通傷害。引擎的 Dragoon 預設有護盾，**兩張原圖都覆寫為 0**，所以本作護盾不能標為地圖原作。

### 行為（OpenBW）

- **護盾與倍率**：見第一節的追加定案表。爆炸傷害對小／中／大為 50／75／100%（L13693–13696）。
- **目標在飛行中死亡**（L12753、L14088）：投射物清除目標，命中時不造成傷害。Phase Disruptor 的飛行行為類型未核。
- **射手在飛行中死亡**（L12753、L13735）：只清射手參照，該發仍可命中。
- **彈跳**（L14095、L14300、L14447）：最多命中 3 次，基礎傷害依序除以 1、3、9，之後才套盾與體型規則。下一目標須為可攻擊的敵方，在命中點半寬 96 px 的方形內搜尋，排除目前與上一目標，取空間索引中第一個（不是最近者）。飛行中該跳目標死亡時該跳無傷害，抵達後仍可續找。射手死亡後不再續彈。
- **Havoc**：FB 與 SPEED 在 elapsed time 600 之後反覆把護盾設為 0。

## 三、暫定建議（未定案）

| 項目 | 建議 |
|---|---|
| 另兩種攻擊類型 | 維持原作普通傷害（與「三者各異」衝突）；若須各異，Mutalisk 另立類別標籤、倍率同普通 |
| E 範圍 | 單體、無濺射（依引擎；「指向性」是否排除範圍傷害待確認） |
| 光球 | 0.12 單位／tick（射程 1.62 約 14 tick）；必中追蹤，冷卻自發射起算 |
| 目標先死 | 無傷害、不改追、不退冷卻 |
| 彈跳 | 命中點半徑 1.5 內最近者，同距取小 id，三目標互異，不足即結束；可打核心 |
| 結算順序 | 同 tick 多發依投射物 id 順序結算 |
| 射程／冷卻 | 1.62／1.62／1.22 單位；19／38／38 tick |
| 過載 | 8 分鐘過載同時清盾、停回盾（仿 Havoc 地圖觸發，非引擎行為） |
| 核心 | 若沿用地圖傷害值，核心 120 換算為 7800，過載每 60 tick 扣 65 |

## 四、待決定參數

**護盾**

- Dragoon 的盾量與血量。引擎預設 100 血／80 盾；FB 為 700 血／0 盾、傷害尺度也不同。保留護盾已定，數值未定；兩種尺度不要混用。
- 回盾換算到 30 Hz 的方式與遊戲速度基準（見未驗證處）。
- 過載後是否清盾、停回（地圖觸發行為，未在引擎行為定案範圍內）。

**其他**

- 另兩種攻擊類型、E 是否完全單體。
- 光球速度、彈跳半徑與倍率、Mutalisk 每跳是否有飛行時間（建議有）。
- 三兵種的信標、價格與數量。

## 五、四席單機版實作（模擬版本 3）

新對局自 2026-11-27 起為版本 4：兵種與傷害規則同本節，可通行道路加寬 10%，見 [BC-SURFACE-HUD](BC-SURFACE-HUD.md)。版本 3 紀錄仍可重播。

同日起新局為版本 5：開場 48 金、每秒 2 金、陸戰隊 7.5 金，見 [BC-AUDIO-ROSTER](BC-AUDIO-ROSTER.md)；下表購兵價格為版本 3、4。

程式：`dev02-four-seats/roster.mjs`（數值與傷害）、`combat.mjs`（索敵、投射物、彈跳）。本節是目前遊戲的行為；第三、四節保留決策歷程，與本節不同處以本節為準，標「暫定」者仍可改。

### 定案與引擎預設

- 三種攻擊標籤：普通（陸戰隊）、指向性爆炸（重騎兵）、彈跳（飛螳）。彈跳倍率**暫定**同普通。
- 指向性爆炸單體，對輕／中／重本體 50／75／100%。取整、整發下限、盾門檻與回盾順序依第一節引擎表。
- 血量／護盾／傷害／冷卻沿用引擎預設（不是地圖值）：陸戰隊 40／0／6／15 frame；重騎兵 100／80／20／30；飛螳 120／0／9／30。
- 飛螳首擊後最多彈跳兩次，傷害除以 3、9。射手死亡不續彈；中間一跳目標死亡仍可續找。
- 三兵種皆可打地面、空中與核心。

### 暫定值

| 項目 | 值 |
|---|---|
| frame 時間 | 42 ms（未驗證）；累計 frame 換算冷卻與回盾 |
| 購兵 | 陸戰隊 5 金×1、重騎兵 12 金×1、飛螳 14 金×1；第四座信標未開放 |
| 移動 | 三兵種同速；飛螳沿同一十字路線飛行，只與空中單位分隔 |
| 射程 | 1.62／1.62／1.215 單位（比例依引擎 128／128／96 px） |
| 投射物 | 光球 0.12、飛螳彈 0.2 單位／tick；陸戰隊即時命中；追蹤必中 |
| 目標先死 | 該發無傷害、不改追、不退冷卻 |
| 射手先死 | 飛行中的該發仍命中 |
| 彈跳搜尋 | 命中點半徑 1.5 內最近敵軍，同距取小編號；無敵軍時可選敵方核心 |
| 結算順序 | 同 tick 先抵達投射物（依編號），再即時攻擊（依射手編號）；擊殺歸致死那一發 |
| 同 tick 陣亡 | 開火在結算前決定：本 tick 陣亡者已發出的即時攻擊仍生效，可同歸於盡（同版本 2） |
| 終局 | 模擬停止；飛行中投射物不再結算，畫面不顯示 |
| 核心 | 900，視為重裝甲；8 分鐘起每 2 秒扣 8 |
| 過載與護盾 | 不清盾、不停回盾（原圖 Havoc 屬地圖觸發，尚未定案） |

飛螳中文名與三兵種模型為本專案原創程序模型，未使用原作素材。模擬版本 1、2（單一兵種）保留供舊紀錄重播與回歸。

驗收：`npm test`（含 `qa-roster.mjs`）與 `npm run test:browser`。固定種子 20261126 加玩家指令的完整對局摘要釘在 `qa-roster.mjs`。
