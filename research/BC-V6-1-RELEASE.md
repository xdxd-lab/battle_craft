# BaattleCraft v6-1（模擬 10）

2026-11-28（台灣時間）｜自 v6-0 升級。特殊技能與展示信標保留在獨立實驗分支，本版不含這些信標或其程式，亦無扣款或觸發。

- 地面用原始兵種各自的矩形碰撞盒及掃掠佔位，有空位才出兵；可排隊、讓位，不以裝甲類型推算佔位。
- 空軍可交錯，在無敵情時緩慢散開，交戰時仍可集中。陸戰隊、刺蛇、重騎兵的起手與釋放分開。
- [九兵種飛行與命中](BC-V6-WEAPON-DELIVERY.md)以 StarEdit 資料及固定版 OpenBW 校正，不宣稱等同原版客戶端全部行為。Wraith 的現行顯示稱「死靈式戰機」。
- 主城 2,700 HP、40 金三艘戰巡、平均每 0.625 秒 4.5 金、地面路寬沿用 v6-0。舊網頁入口保留模擬 8，舊重播保留所記錄版本的行為。

驗證：`npm run build`、`npm test`、`npm run test:combat`、`BC_SIM_VERSION=10 node dev02-four-seats/qa-v9-match.mjs`。用 `node dev02-four-seats/qa-web-v6.mjs` 檢查桌面和橫式手機的實際 WebGL 入口；設 `BC_LEGACY_V6=1` 檢查 v6-0 舊入口。地面模型的繪圖插值仍可能稍微交疊；線上對戰與原版特殊英雄規則不在本版範圍。
